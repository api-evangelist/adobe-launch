The latest info for anyone who has built CEP Extensions or UXP plugins or has hosted their work in Adobe Marketplace. Unified eXtensibility Platform (UXP) We recently released UXP v8.0 in Photoshop 2025 (v26) and InDesign v20.0 with key features mentioned below: Support for new Spectrum Web Components to provide a wholesome UI library that aligns with Adobe’s Design Language — Spectrum The much-awaited local HTML support for Webview . Webviews are particularly helpful for features that are not innately supported in UXP, such as animation, 3D APIs, etc.
